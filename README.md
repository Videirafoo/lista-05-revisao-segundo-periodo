# Revisão de Algoritmos em Python

Repositório acadêmico com exercícios de revisão de **Algoritmos e Lógica de Programação** em Python.

## Estrutura

O projeto possui seis exercícios independentes e um arquivo principal que executa todos em sequência:

```text
exercicio1.py
exercicio2.py
exercicio3.py
exercicio4.py
exercicio5.py
exercicio6.py
main.py
```

## Como executar

Para executar a revisão completa:

```bash
python main.py
```

Para executar somente um exercício:

```bash
python exercicio1.py
```

## Objetivo

Consolidar conceitos fundamentais de programação antes das avaliações da disciplina, mantendo cada exercício separado para facilitar estudo e revisão.

- Python 3
- Visual Studio Code
