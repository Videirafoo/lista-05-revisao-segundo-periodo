
## Como usar para revisar de verdade

1. tente resolver cada questão sem consultar o código;
2. marque onde ficou em dúvida;
3. execute e compare sua solução;
4. explique a lógica sem ler o arquivo;
5. altere valores de entrada e teste novos casos;
6. refaça, no dia seguinte, apenas o que apresentou dificuldade.

## Checklist de domínio

Antes de considerar o conteúdo revisado, verifique se você consegue:

- ler e validar entradas;
- usar condicionais;
- escrever laços;
- criar funções;
- trabalhar com listas;
- identificar erros simples;
- explicar o fluxo do programa.
